What I am learning right now

  <head>
    <meta charset="UTF-8" />
    <title>Page title</title>
  </head>
  <body>
    <h1>Hello</h1>
  </body>

To open it in a browser, save it and press Cmd + O. To find a file in VS Code, press Cmd + P.

Glossary

Terms from my day job
Microservice
One small service that does one job and talks to the others over HTTP or a message queue.
REST API
An interface where URLs name resources and HTTP methods say what to do with them.
Dependency Injection
The framework hands an object what it needs instead of the object constructing it. The core idea behind Spring's IOC container.
ORM
Object-Relational Mapping. Hibernate turns database rows into Java objects and back.
Message broker
A middleman that takes messages from publishers and delivers them to subscribers, so neither needs to know about the other.
Terms from week 1 of the roadmap
  • Client — the thing asking. Usually a browser.
  • Server — the machine that answers.
  • DNS — turns a name like example.com into an IP address.
  • 200 — it worked
  • 401 — who are you? (not logged in)
  • 403 — I know who you are, and no
  • 404 — nothing at that address
  • 500 — the server broke

1. display — what kind of box is this?

Notice that the yellow inline element ignores the width you give it. That is not a bug — inline boxes are sized by their content, full stop.

2. position — where does the box sit?

The purple pill is absolute. It anchors to the dashed stage because that stage is position: relative. Remove the relative and it would fly out to the page corner instead.

7. The box model — content-box vs border-box

Both boxes say width: 220px. Both have 20px padding and a 6px border. Measure them with DevTools: the first is 272px wide, the second is exactly 220px. The dashed ruler underneath each one is the same length, so the difference is easy to see.

box-sizing: content-box (browser default)
width: 220px
+ padding 20×2
+ border 6×2
= 272px on screen
box-sizing: border-box (what we use)
width: 220px
padding and border grow inward

= 220px on screen

This is why css/base/reset.css opens by setting box-sizing: border-box on every element. From then on, the number you write is the number you get.
